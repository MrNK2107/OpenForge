## 1. 🎯 Executive Summary

### 1.1 Problem Statement

Starting or contributing to open-source projects presents significant barriers:

- **For Idea Owners:**
  - Don't know how to structure a contributor-friendly repository
  - Lack time to create proper documentation, issue templates, CI/CD
  - Struggle to find aligned collaborators with right skills
  - Ideas die in notes/Discord messages without execution

- **For Contributors:**
  - Overwhelmed by massive codebases and unclear onboarding
  - Can't find projects matching their skills/interests/time commitment
  - "Good first issues" are often outdated or poorly scoped
  - No clear path from first contribution to meaningful involvement

- **For the OSS Ecosystem:**
  - Knowledge silos and duplicated efforts
  - High abandonment rate for new projects
  - Fragmented discovery across GitHub, Reddit, Discord, Twitter

### 1.2 Proposed Solution

**OpenForge** is a web platform that transforms raw project ideas into structured, contributor-ready repositories in minutes. It provides:

- **Idea Pitch Board:** Submit and discover project ideas with rich metadata
- **Auto-Repo Generator:** One-click GitHub repo creation with best-practice scaffolding
- **Contributor Matching:** Skill/interest-based matching between projects and contributors
- **Modular Task Board:** Auto-generated and manual tasks with clear scope and difficulty
- **Public Dashboard:** Transparent project lifecycle tracking synced with GitHub
- **Open API:** Extensible for universities, bootcamps, NGOs, and tooling integrations

### 1.3 Success Metrics (MVP)

| Metric | Target |
|--------|--------|
| Time from idea → contributor-ready repo | < 3 minutes |
| Successful contributor matches per project | ≥ 2 in first week |
| User satisfaction (post-demo survey) | ≥ 4.2/5 |
| Projects with first external PR | ≥ 30% within 2 weeks |

### 5.3 Detailed Schema (PostgreSQL)

```sql
-- Users table
CREATE TABLE users (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    github_id BIGINT UNIQUE NOT NULL,
    username VARCHAR(100) NOT NULL,
    email VARCHAR(255),
    avatar_url TEXT,
    bio TEXT,
    roles TEXT[] DEFAULT '{}',
    availability VARCHAR(50),
    github_access_token TEXT, -- encrypted, server-side only
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- Tags table (unified for skills, tech, domains)
CREATE TABLE tags (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    name VARCHAR(100) UNIQUE NOT NULL,
    category VARCHAR(50) NOT NULL, -- 'tech', 'domain', 'role', 'difficulty'
    color VARCHAR(7), -- hex color for UI
    created_at TIMESTAMPTZ DEFAULT NOW()
);

-- User skills (junction table)
CREATE TABLE user_skills (
    user_id UUID REFERENCES users(id) ON DELETE CASCADE,
    tag_id UUID REFERENCES tags(id) ON DELETE CASCADE,
    proficiency VARCHAR(20) DEFAULT 'learning', -- 'learning', 'intermediate', 'expert'
    PRIMARY KEY (user_id, tag_id)
);

-- Projects table
CREATE TABLE projects (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    owner_id UUID REFERENCES users(id) ON DELETE CASCADE,
    title VARCHAR(255) NOT NULL,
    description TEXT,
    status VARCHAR(50) DEFAULT 'draft', -- 'draft', 'seeking', 'active', 'paused', 'archived'
    difficulty VARCHAR(50), -- 'beginner', 'intermediate', 'advanced'
    scope VARCHAR(50), -- 'weekend', 'side-project', 'startup'
    time_commitment VARCHAR(50), -- '1-5 hrs/week', '5-10 hrs/week', '10+ hrs/week'
    github_repo_url TEXT,
    github_repo_id BIGINT,
    template_type VARCHAR(50), -- 'web-app', 'cli', 'library', 'data', 'mobile'
    license VARCHAR(50) DEFAULT 'MIT',
    is_public BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- Project tags (junction table)
CREATE TABLE project_tags (
    project_id UUID REFERENCES projects(id) ON DELETE CASCADE,
    tag_id UUID REFERENCES tags(id) ON DELETE CASCADE,
    PRIMARY KEY (project_id, tag_id)
);

-- Project roles needed
CREATE TABLE project_roles_needed (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    project_id UUID REFERENCES projects(id) ON DELETE CASCADE,
    role_name VARCHAR(100) NOT NULL, -- 'frontend', 'backend', 'design', 'docs', 'devops'
    filled BOOLEAN DEFAULT FALSE,
    filled_by UUID REFERENCES users(id)
);

-- Project members
CREATE TABLE project_members (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    project_id UUID REFERENCES projects(id) ON DELETE CASCADE,
    user_id UUID REFERENCES users(id) ON DELETE CASCADE,
    role VARCHAR(100), -- 'owner', 'maintainer', 'contributor', 'mentor'
    status VARCHAR(50) DEFAULT 'active', -- 'active', 'inactive', 'left'
    joined_at TIMESTAMPTZ DEFAULT NOW(),
    UNIQUE (project_id, user_id)
);

-- Join requests
CREATE TABLE join_requests (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    project_id UUID REFERENCES projects(id) ON DELETE CASCADE,
    user_id UUID REFERENCES users(id) ON DELETE CASCADE,
    message TEXT,
    status VARCHAR(50) DEFAULT 'pending', -- 'pending', 'accepted', 'declined', 'withdrawn'
    created_at TIMESTAMPTZ DEFAULT NOW(),
    responded_at TIMESTAMPTZ,
    UNIQUE (project_id, user_id, status)
);

-- Tasks
CREATE TABLE tasks (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    project_id UUID REFERENCES projects(id) ON DELETE CASCADE,
    title VARCHAR(255) NOT NULL,
    description TEXT,
    status VARCHAR(50) DEFAULT 'backlog', -- 'backlog', 'in_progress', 'review', 'done'
    difficulty VARCHAR(50), -- 'easy', 'medium', 'hard'
    labels TEXT[] DEFAULT '{}', -- 'good-first-issue', 'bug', 'feature', 'docs'
    assignee_id UUID REFERENCES users(id),
    github_issue_url TEXT,
    github_issue_number INT,
    effort_estimate VARCHAR(20), -- 'XS', 'S', 'M', 'L', 'XL'
    due_date DATE,
    created_by UUID REFERENCES users(id),
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- Task comments
CREATE TABLE task_comments (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    task_id UUID REFERENCES tasks(id) ON DELETE CASCADE,
    user_id UUID REFERENCES users(id) ON DELETE CASCADE,
    content TEXT NOT NULL,
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- Notifications
CREATE TABLE notifications (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID REFERENCES users(id) ON DELETE CASCADE,
    type VARCHAR(100) NOT NULL, -- 'match_found', 'join_request', 'request_accepted', 'task_assigned', etc.
    title VARCHAR(255),
    message TEXT,
    payload JSONB DEFAULT '{}',
    read BOOLEAN DEFAULT FALSE,
    created_at TIMESTAMPTZ DEFAULT NOW()
);

-- GitHub sync logs
CREATE TABLE sync_logs (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    project_id UUID REFERENCES projects(id) ON DELETE CASCADE,
    event_type VARCHAR(100), -- 'repo_created', 'issues_synced', 'prs_synced', 'webhook_received'
    payload JSONB DEFAULT '{}',
    status VARCHAR(50), -- 'success', 'failed', 'partial'
    error_message TEXT,
    created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Project stars (user bookmarks)
CREATE TABLE project_stars (
    user_id UUID REFERENCES users(id) ON DELETE CASCADE,
    project_id UUID REFERENCES projects(id) ON DELETE CASCADE,
    created_at TIMESTAMPTZ DEFAULT NOW(),
    PRIMARY KEY (user_id, project_id)
);

-- Indexes for performance
CREATE INDEX idx_projects_status ON projects(status);
CREATE INDEX idx_projects_owner ON projects(owner_id);
```

### Appendix B: Matching Algorithm Pseudocode

```python
def calculate_match_score(user, project):
    # Skill overlap (Jaccard similarity)
    user_skills = set(user.skills)
    project_tags = set(project.tech_tags + project.domain_tags)
    skill_overlap = len(user_skills & project_tags) / len(user_skills | project_tags)
    
    # Difficulty alignment
    difficulty_match = 1.0 if user.preferred_difficulty == project.difficulty else 0.5
    
    # Availability alignment
    availability_match = 1.0 if user.availability >= project.time_commitment else 0.7
    
    # Role match
    role_match = 1.0 if any(role in user.roles for role in project.roles_needed) else 0.3
    
    # Weighted score
    score = (
        skill_overlap * 0.4 +
        difficulty_match * 0.2 +
        availability_match * 0.2 +
        role_match * 0.2
    )
    
    return score

def get_matches(user, all_projects, top_n=10):
    matches = []
    for project in all_projects:
        if project.status == 'seeking' and user.id not in project.members:
            score = calculate_match_score(user, project)
            if score > 0.5:  # Minimum threshold
                matches.append((project, score))
    
    matches.sort(key=lambda x: x[1], reverse=True)
    return matches[:top_n]
```
